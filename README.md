# java-gym-master

Администраторы чаще всего выполняют с расписанием следующие задачи:

- **Получение всех тренировок, упорядоченных по времени начала, за конкретный день** недели.
Утром, придя на работу, администратор распечатывает список всех тренировок на сегодня — с утра и до вечера —
и вывешивает его на доске, чтобы все посетители могли его увидеть.
Кроме того, часто новые посетители звонят и спрашивают, какие есть тренировки сегодня.
Тогда этот список тоже пригодится.
Так как первый клиент может прийти почти сразу за администратором и нужно обязательно успеть распечатать список,
то этот запрос должен выполняться очень быстро —
требуемая алгоритмическая сложность O(1).

- **Получение всех тренировок, начинающихся в конкретное время, за конкретный день недели**.
Самый частый вопрос, который клиенты задают администратору по телефону:
«Какие есть тренировки сегодня в такое-то время?»
И администратор должен очень быстро ответить на этот вопрос.
Для этого запроса допустима сложность O(log(n)) или быстрее.

- **Добавление новой тренировки в расписание**.
Новая тренировка может быть добавлена для любого дня недели и любого времени.
При добавлении администратор выбирает группу и тренера.
Так как это обычно происходит заранее, это не столь требовательная по времени выполнения операция,
и ограничения относительно её алгоритмической сложности отсутствуют.
